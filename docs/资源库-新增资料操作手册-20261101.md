# 资源库 · 新增资料操作手册

> 适用：`link-edu` 前端「灵感资料室 / 资源库」页面
> 更新：2026-11-01（资源库扩充后共 36 份资料、9 个分类）
> 性质：内部操作说明。文中「临客整理 / 临客绘制」条目为自编训练材料，非正式国标。

## 一、这个资源库怎么工作

没有上传按钮，也没有后台管理页。加资料 = **放文件 + 加一条数据**：

| 你要改的 | 路径 |
|---|---|
| 文件放哪 | `frontend/public/library/` 下的 `original/`、`preview/`、`thumbs/`、`covers/` |
| 数据写哪 | `frontend/src/data/libraryResources.js` |
| 封面兜底 | `frontend/src/data/libraryBoardCovers.js` |
| 阅读器能力 | `frontend/src/views/ResourcesView.vue` |

浏览器访问路径就是 `/library/original/文件名`。**文件名只用英文、数字和连字符**，不要用中文或空格（部分部署环境会 404）。

## 二、目录分工

| 目录 | 放什么 |
|---|---|
| `original/` | Markdown 原稿、Word/PDF 原件、视频、图示 |
| `original/videos/` | mp4 视频 |
| `original/diagrams/` | SVG 图示 |
| `preview/` | PDF 预览版（阅读器 iframe 用） |
| `thumbs/` | 卡片小图（视频封面等，640px 宽足够） |
| `covers/` | 分类网格大封面、文稿封面 `doc-*.svg` |

## 三、条目字段速查

```js
{
  id: "唯一英文 id",              // 不能重复，改 id 等于换一条资料
  title: "标题",
  category: "分类名",             // 必须是 libraryTabs 里的值，写错就不会出现在分类里
  description: "40—60 字说明",     // 说清“这份资料能拿来干什么”
  source: "来源",                 // 临客整理 / 教育部 / Coverr ...
  year: "2026",
  stage: "小学 | 中学 | 幼儿园 | 多学段 | 通用",
  format: "站内阅读 / MD",         // 阅读器底部和卡片上显示
  pages: 5,                       // 可选：PDF 页数
  duration: "00:14",              // 可选：视频时长
  recommended: true,              // 可选：卡片墙优先展示
  coverTheme: "orange",           // orange indigo rose violet blue green amber
  coverMark: "板",                // 卡片封面上的大字
  coverLabel: "板书分区",
  coverTitle: "三块板面怎么分",
  readType: "markdown",           // markdown | pdf | video | image | external
  readUrl: "/library/original/xxx.md",
  downloadUrl: "/library/original/xxx.md",
  downloadName: "下载时的文件名.md",
  thumbnail: "/library/covers/doc-xxx.svg",  // 分类网格封面
  position: { left: 2, top: 24, rotate: -3, z: 5 }  // 卡片墙位置，现由页面自动排
}
```

## 六、加完怎么自查（5 分钟）

1. **文件在不在**：每个 `readUrl` 都要能对应到真实文件。
2. **能构建**：`cd frontend && npm run build`，没有报错。
3. **能打开**：`启动前端.bat` → 登录 → 资源库 → 找到新卡片 → 点开看内容。
4. **分类计数对不对**：分类浏览上方的图例数字 +1 了没有。
5. **封面不是空白**：分类网格里每张卡都有图（没有 `thumbnail` / `boardImage` 时会用兜底封面）。

## 七、素材限制（踩过的坑）

- **GitHub 单文件上限 100MB**，超了 push 直接失败；单条视频建议压在 20MB 内。
- **浏览器只认 mp4（H.264）和 webm**，mov / avi 播不了。
- **视频不设封面，卡片就是空白框**：用 `thumbs/` 里的 jpg 或 Coverr / Pexels 的缩略图。
- **不要手改构建产物**：`dist/` 只由 `npm run build` 生成。
