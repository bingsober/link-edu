# 结构化面试 · 观点分析类答题框架

> 临客整理 · 训练材料，非官方题库或评分标准。示例题只用于练习作答结构，不代表真题。

## 一、这类题长什么样

给你一句话或一对矛盾：教育名言之类、社会争议（「减负后家长更焦虑了」）、两种做法（「严师出高徒」与「赏识教育」）。考的是**你有没有自己的教育立场，以及能不能辩证地说理**。

示例（练习用）：

- 有人说「没有教不好的学生，只有不会教的老师」，你怎么看？
- 有人认为惩罚能立规矩，有人认为赏识才有用，你怎么看？
- 「双减」之后，有家长反而更焦虑，你怎么看这种现象？

## 二、120 秒作答结构

1. **亮立场（15 秒）**：一句话给出你的基本判断，别骑墙。
   - 「这句话有它提醒教师的价值，但把学生的问题全部归于教师，我认为不成立。」
2. **说合理处（30 秒）**：先承认对的部分——站在谁的角度、回应了什么问题。
3. **说局限处（40 秒）**：指出过头或片面的地方，最好落到教育规律或学生差异上。
   - 「学生的成长受家庭、同伴、社会多方面影响；教师能做的是在自己的环节里做到专业与尽责。」
4. **落到做法（25 秒）**：作为老师你具体怎么做——两句就够。
   - 「对学困生，我会先诊断卡点，再小步子提要求；同时如实与家长沟通期望。」

## 三、两个加分动作

1. **把名言翻译成教育行为**：别背语录，说「这句话在教学里意味着什么」。
2. **用学生个案说话（不指名）**：「我遇到过高年级还不愿开口读课文的学生，逼是没有用的，得先让他有一次成功的朗读体验」——具体比华丽加分。

## 四、90 秒速练法

1. 抽一句教育名言，60 秒内说出「合理处一句话 + 局限处一句话 + 我会怎么做一句」。
2. 找对立观点题，练「各打五十大板但不骑墙」：两边都有理，但我的做法有倾向。
3. 回放检查：有没有至少一处具体到「课堂上会发生什么」。
