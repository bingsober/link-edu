# 结构化面试 · 应急应变类答题框架

> **用途**：应对“课堂上突然发生……你怎么办”的设问（临客整理）。  
> **性质**：训练框架，非标准答案；真实处置仍要遵守所在学校的安全与管理制度。  
> **配套**：`结构化面试 · 教育现象类答题框架`、`试讲答辩 20 问`。

## 一、这类题到底在考什么

不是考你会不会处理，而是考三件事：

1. **你会不会先稳住场面**（而不是先讲道理）。
2. **你知不知道谁该负责**（有没有乱承诺、越权处理）。
3. **你会不会把一次意外变成教育机会**。

## 二、四步结构（建议 60—90 秒）

### 第 1 步：稳住（10 秒）

先处理“当下”，一句话交代清楚：

- 有安全风险：**“先让全班停下手上的事，把学生带离/疏散到安全位置，同时请班干部去叫班主任或校医。”**
- 有情绪冲突：**“先把两个人分开，各自冷静一分钟，不在全班面前追问谁对谁错。”**
- 有秩序混乱：**“用一句明确的指令收拢注意力，比如‘全体把笔放下，看黑板’。”**

要点：**先安全、再秩序、后教育**，顺序不能倒。

### 第 2 步：处置（20 秒）

说清楚“谁来做什么”，要具体到动作：

- 谁负责陪护，谁负责联系，谁负责记录；
- 需要上报的，明确“第一时间报告班主任 / 年级组 / 学校”；
- 不越权：不擅自承诺处分、不擅自对外发布信息、不当场给学生“定性”。

### 第 3 步：教育（20 秒）

场面稳下来之后，把事件转成教育资源，但要注意场合：

- 涉及隐私的个别问题**课后单独谈**，不在班上讲细节；
- 涉及全班的共性问题（如起哄、嘲笑），可以当场用两分钟做一个“换位”讨论；
- 明确规则时用行为描述，不贴标签：说“刚才有人插话打断了发言”，而不是“你们就是不尊重人”。

### 第 4 步：复盘（15 秒）

最后一句要落到“以后怎么少发生”：

- 自己这堂课的设计有没有漏洞（环节太长、任务不清、材料不够）；
- 班级约定是否需要补一条；
- 是否需要和家长沟通，沟通的重点是什么。

## 三、四条底线（答错就扣分）

| 底线 | 错误示范 |
|------|----------|
| 不体罚、不变相体罚 | “让他站到教室后面反省一节课” |
| 不当众羞辱 | “当着全班把作业本扔回去” |
| 不隐瞒安全事件 | “小事，不用告诉学校” |
| 不越权处置 | “我直接给他记过” |

## 四、常见题型的处置顺序

- **学生突然晕倒 / 受伤**：停止活动 → 判断意识 → 呼叫校医与班主任 → 疏散围观 → 通知家长 → 记录。
- **学生课堂冲突动手**：分开 → 检查伤情 → 分别冷静 → 了解经过 → 按校规上报 → 后续调解。
- **学生当面顶撞**：不接情绪 → 给台阶（“先坐下，下课我们单独说”）→ 课后谈 → 明确边界。
- **设备/材料突然故障**：先给替代任务（口头举例、同桌互说）→ 快速修复 → 修不好就改教学设计，不硬撑。

## 五、自练方法（15 分钟）

1. 让同伴随机报一个情境，你 10 秒内说出第一句话（只练“稳住”这一句）。
2. 完整答一遍并录音，检查是否出现“我觉得他应该……”这种越权表述。
3. 把答案压缩到 60 秒再说一次——应急题答太长，反而显得没重点。

> 面试现场提醒：这类题允许你停顿两秒想顺序，但不要用“这个问题我要分三点回答”开场拖时间。
