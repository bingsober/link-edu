# 结构化面试 · 组织活动类答题框架

> 临客整理 · 训练材料，非官方题库或评分标准。示例题只用于练习作答结构，不代表真题。

## 一、这类题长什么样

让你牵头办一件事：主题班会、家长会、春游、读书节、运动会入场式。考的不是你多有创意，是**你做事有没有顺序、有没有安全意识、有没有把育人目的挂在前面**。

示例（练习用）：

- 学校让你组织一次「垃圾分类」主题班会，你怎么开展？
- 班里要开本学期第一次家长会，你如何筹备？
- 学校安排你带学生参加一日研学活动，你会做哪些准备？

## 二、120 秒作答结构

1. **一句目的（15 秒）**：先说这次活动要让学生「获得什么」，别急着说流程。
   - 「组织这次班会，我是希望学生不仅知道分类方法，更能在家 里带动全家去做。」
2. **事前（40 秒）**：准备阶段三件事——摸底、方案、报备。
   - 摸底：学生现有认知/家庭情况；方案：时间、流程、分工；报备：向年级或领导报方案，涉及外出要家长知情同意。
3. **事中（40 秒）**：抓两条线——活动线（流程推进、环节衔接）和秩序线（安全、纪律、突发预案）。说两三个具体环节就够，不要报流水账。
4. **事后（25 秒）**：复盘与延伸——收集反馈、展示成果、把一次活动变成持续教育（比如设「分类督导员」岗位）。

## 三、让答案不像模板的三个细节

1. **提到具体学生的安排**：内向的孩子给什么角色、活跃的孩子怎么用，一句话就够。
2. **提到预算与安全**：涉及外出必说「报备、保险、家长知情」，这是评分硬项。
3. **提到留痕**：照片、小结、家长反馈，说明你做事闭环。

## 四、90 秒速练法

1. 抽一道示例题，90 秒出声作答并录音。
2. 回放检查四拍是否齐全：目的 → 事前 → 事中 → 事后，缺哪拍补哪拍。
3. 再用同一道题，限时 60 秒压缩版——练「考官打断时先说哪句」。
