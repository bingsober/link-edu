# 教学设计一页纸模板

> **用途**：把一节课压缩到一页，逼自己想清楚“教什么、怎么教、怎么知道教会了”（临客整理）。  
> **性质**：模板，可复制到教案本或电子文档；非正式国标。  
> **配套**：`学情分析模板`、`10 分钟片段时间分配表`、`板书分区示意`（图示）。

### 2. 学情（三句话说完）

- 学生已经会：
- 学生容易错在：
- 因此这节课的起点是：

### 3. 目标（写完要能检验）

| 维度 | 目标 | 怎么看出来达成了 |
|------|------|------------------|
| 知识与技能 | 能说出 / 能做出…… | 课堂练习第 __ 题 |
| 过程与方法 | 经历……的过程 | 学生能说出“我是怎么想的” |
| 情感态度 | 感受到 / 愿意…… | 课堂发言或小结里的表达 |

目标写法提醒：**用可观察的动词**（说出、指出、比较、设计），不用“了解、体会、感受”这类看不见的词——除非你能说清从哪看出来。

### 4. 重点与难点

- **重点**：这节课必须学会的（通常对应目标第一条）。
- **难点**：学生最容易卡住的地方（通常来自学情第二条）。
- **突破办法**：一句具体做法（用图？用反例？用操作？），不要写“教师引导”。

### 5. 教学环节（核心表格）

| 时间 | 环节 | 教师活动 | 学生活动 | 设计意图 |
|------|------|----------|----------|----------|
| 0—1′ | 导入 | | | |
| 1—4′ | 新授 | | | |
| 4—7′ | 练习 | | | |
| 7—9′ | 巩固 | | | |
| 9—10′ | 小结 | | | |

填写要求：

- “学生活动”一栏**不能空**，空着说明这节课是教师独白。
- “设计意图”一栏写**为什么这样安排**，不写“为了完成教学任务”。

### 6. 板书设计

用方框画三块：标题区 / 主板书 / 副板书。文字版可以这样写：

```

[主板书]              [副板书]
概念：               追问：
图例：               易错：
```

## 二、写完后的三分钟自检

1. 遮住“教师活动”一栏，只看“学生活动”——这节课学生到底做了什么？
2. 目标里的每一条，能不能在环节表里找到对应的落实处？
3. 如果只剩 8 分钟，你会砍哪一段？（砍不出来的设计，说明没有主次）

## 三、常见问题

- **目标写成内容**：“认识分数”是内容，不是目标；目标应是“能指出一个整体的二分之一”。
- **环节没有时间**：不写时间，实际上课时一定会前松后紧。
- **设计意图全是套话**：“培养学生的思维能力”——哪一步培养了？说具体。
- **板书最后才想**：板书是结构的外化，最好在写环节时就同步画。

> 使用方法：先用这张表写 3 份完整教案，再尝试只写“目标 + 难点 + 环节表”三块——熟练后这三块就够支撑一节课。
